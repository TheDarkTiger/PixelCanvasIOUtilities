## Tampermonkey scripts
Small scripts to help one thing or an other.  
I prefer to do multiple little scripts than a big one.

### Change cursor
Change the 'hand' cursor to a smaller one.  
I like to work somewhat zoomedout, and the hand cursor blocked the view.  
I previously used one created by _0xA663_ , but this one is created from scratch. Thanks to him for the old one!

### Remove map buttons
With the new update, I sometime clicked on the location buttons, wasting time to go back where I was 'working'.  
This script removes the buttons "Explore a random city" and "Go to my location".
